A block theme for blogs and portfolios, built with theme.json and the Site Editor.

== Description ==

Keepsake is a block theme for blogs, portfolios and similar sites. It has a light header with site title, tagline and navigation, centered post titles with an author, date and comments row, excerpts with a "continue reading" link, a highlighted "Featured" label for sticky posts, and its own styled comments section.

Colors, typography, spacing and layout are all controlled through theme.json and the Site Editor, so no build step or extra plugins are needed. The content width is 640px and the wide width is 1170px; wide and full-width blocks are supported, and featured images can be set to wide or full width in the editor.

Templates included: front page and posts index, single post, page, archive, search, 404, and a "Home" page template. Header and footer are template parts you can edit in the Site Editor.

== Frequently Asked Questions ==

= How do I change the colors, fonts or layout? =

Open Appearance > Editor > Styles. Everything defined in theme.json can be changed there.

= Does the theme load anything from other websites? =

No. The fonts are bundled with the theme and no external scripts, styles or images are loaded.

= Does the theme collect any data? =

No. The theme does not track visitors or collect any data.

= Does the theme support sidebars or the Customizer? =

No. It is a block theme: use the Site Editor to add blocks to any template or template part.
